# Running on iPhone / iOS / הרצה על iPhone

## Overview / סקירה כללית

You can run the Cybersecurity Learning Assistant on your iPhone using Python apps available on the App Store. Here are the recommended methods:

---

## Method 1: Pythonista (Recommended) ⭐

**Pythonista** is a full Python IDE for iOS that supports Python 3.

### Installation Steps:

1. **Download Pythonista**
   - Open the App Store on your iPhone
   - Search for "Pythonista 3"
   - Install the app (~$10 one-time purchase)

2. **Get the Code**
   - Option A: Use the built-in browser in Pythonista to download from GitHub
   - Option B: Use iCloud Drive or Dropbox to sync files
   - Option C: Copy-paste the code directly

3. **Setup Instructions:**

   ```
   1. Open Pythonista on your iPhone
   2. Tap the wrench icon (⚙️) → "Download"
   3. Enter: https://github.com/ghareebmahmoud61-del/mahmoud
   4. Or manually create files:
      - Create "cyber_learning_assistant.py"
      - Create "interactive_assistant.py"
      - Create "professional_assistant.py"
   ```

4. **Run the Assistant:**
   - Tap on `interactive_assistant.py`
   - Tap the ▶️ (Play) button
   - Use the interactive menu

### Features on iPhone with Pythonista:
- ✅ Full Python 3 support
- ✅ Touch-friendly console
- ✅ Save/load sessions
- ✅ File management
- ✅ Works offline

## Troubleshooting on iPhone

### Issue: Can't install Python apps
**Solution:** Make sure you have iOS 12 or later

### Issue: Import errors
**Solution:** All modules used are Python standard library - no external dependencies needed

### Issue: Screen too small
**Solution:** 
- Rotate to landscape for wider view
- Use zoom features
- Increase font size in app settings

### Issue: Keyboard covering output
**Solution:** 
- Tap outside keyboard to dismiss
- Scroll up to see previous output
- Use external keyboard if available

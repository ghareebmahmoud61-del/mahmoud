# mahmoud

A GitHub Copilot Custom Agent template repository.

## Overview

This repository provides a template for creating custom GitHub Copilot agents. Custom agents extend GitHub Copilot's capabilities with specialized knowledge and behaviors tailored to your specific needs.

## Getting Started

📖 **[Read the RUN Guide](RUN.md)** for complete instructions on:
- How to configure your custom agent
- How to test locally
- How to deploy and use your agent

## Quick Setup

1. Edit `.github/agents/my-agent.agent.md` with your agent's configuration
2. Commit and push to the default branch
3. Your custom agent will be available in GitHub Copilot

For detailed instructions, see [RUN.md](RUN.md).

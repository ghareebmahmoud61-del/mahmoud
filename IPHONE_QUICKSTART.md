# 📱 Quick Start: iPhone/iOS

## Super Fast Setup (5 minutes)

### Step 1: Install Python App (Choose One)

**Option A: Pythonista** (Best - $9.99)
- App Store → Search "Pythonista 3" → Install

**Option B: Pyto** (Free)
- App Store → Search "Pyto Python 3" → Install

### Step 2: Get the Code

#### In Pythonista:
```
1. Open Pythonista
2. Tap + (New File)
3. Name it: mobile_assistant.py
4. Copy-paste code from:
   github.com/ghareebmahmoud61-del/mahmoud/blob/main/mobile_assistant.py
```

#### In Pyto:
```
1. Open Safari → GitHub repo
2. Download mobile_assistant.py
3. Share → Save to Files
4. Open in Pyto
```

### Step 3: Run!

```
1. Tap the file in your Python app
2. Tap ▶️ (Play/Run button)
3. Enter your name
4. Choose from menu (0-9)
5. Start learning! 🎓
```

## Pro Tips for iPhone

### Best Experience:
- 📱 Use **portrait mode** for reading lessons
- ⌨️ Switch to **landscape** when typing notes
- 💾 **Save often** (option 7) - iOS can close apps
- 🔊 Use **voice dictation** for longer notes
- 📲 Add to **Home Screen** for quick access

### Battery Saver:
- Close other apps while learning
- Enable Low Power Mode for longer sessions
- Download lessons for offline use

### Dyslexia Support on iPhone:
- ✅ Larger text (iOS Settings → Display)
- ✅ Voice dictation (no typing needed)
- ✅ VoiceOver support
- ✅ Auto-save your work

## Troubleshooting

### "Module not found"
→ Make sure `cyber_learning_assistant.py` is in the same folder

### "Can't save"
→ Check file permissions in app settings

### Screen too small
→ Use zoom or increase font size in app settings

### Keyboard blocking text
→ Tap outside keyboard area to dismiss it
